# Framed transport tutorial
Request: A5 seq syndrome XOR(previous 3). Response: 5A seq prediction cycles_lo cycles_hi XOR(previous 5). Only predictions 0/1 are legal. Parser skips leading garbage and holds at most five partial bytes between calls; invalid checksum/prediction fails closed. exchange validates one expected sequence and raises on timeout or short write. One outstanding request only. After failure close/reopen and reset the endpoint, do not blindly retry or reuse partial state. Sequence wraps modulo 256; this is not replay protection. Endpoint reads and writes must be bounded. Serial uses bounded reads and write timeout. Loopback validates framing but runs Python LUT, reports zero placeholder cycles, and is NOT FPGA or RTL simulation.
