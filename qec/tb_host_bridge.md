# Host UART bridge testbench
Compiled and run by rtl_bridge.py, not a stand-alone production top. +shots=N selects 1..4096 four-byte host request packets from requests.mem. 32 simulated clock ticks per UART bit accelerate functional serial transport through the actual top_qec_uart RTL. Each response is independently sampled at bit centers, stop-bit checked, and written bytewise to responses.mem. The bench waits for six response bytes before sending the next shot; no streaming claims. A global HDL timeout prevents hangs. Host-side parser verifies wire checksum/sequence/prediction and the test compares raw shots to regenerated Stim samples. Logs are in qec/.rtl and never treated as board evidence.
